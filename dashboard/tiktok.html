    📖 Panduan Dashboard TikTok
    • Semua Niche: Tapis leads mengikut niche (Jualan Kereta, Servis Bengkel, Aksesori Kereta).
    • Semua Kawasan: Tapis leads mengikut negeri/daerah Malaysia.
    • Semua Brand: Tapis leads mengikut brand kereta (Proton, Perodua, Honda, Toyota).
    • Search: Cari nama, niche atau daerah dalam kotak carian.
    • Intent Score: Urutkan leads mengikut skor (Tinggi ke Rendah, Terbaru, Nama A-Z).
    • Apply Filters: Terapkan semua filter yang dipilih kepada jadual.
    • Reset: Kosongkan semua filter dan paparkan semula semua baris.
    • Run Scout Agent: Jalankan agen pengesan prospek baru.
    • Set Targets & Butang Hunt: Masukkan username sasaran di Set Targets. Klik 🎯 Hunt untuk ubah status target kepada hunting. Hanya target dengan status hunting yang akan dipantau oleh Python Hunter.
    • Tab DM: Lead Aktif paparkan leads yang belum DM. Sembunyi (Dah DM) paparkan leads yang sudah DM. Klik 📩 Tanda Dah DM pada setiap baris untuk pindah lead kepada tab Sembunyi.
    • Mode Farming: Paparkan senarai sasaran harian (skor ≥ 0.6) untuk follow & like.
    • Content War: Alat bantu cipta content TikTok (keywords, objection scripts, bait captions).
    • Hunter Control Panel: Tekan ▶️ Start Hunter untuk jalankan tiktok_hunter.py, dan ⏹️ Stop Hunter untuk berhenti. Nota: Pastikan anda telah menjalankan python backend/run_server.py di terminal laptop sebelum menekan butang Start/Stop.
    • Auto-Sync: Bila Hunter di-stop, data leads akan dihantar ke Supabase secara automatik.
